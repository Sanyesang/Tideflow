# 潮序 Tideflow 设计记录

## 品牌方向

- 产品工作名：**潮序 Tideflow**；“潮”表达市场节奏，“序”表达策略与风控的秩序。商标和域名尚未检索，不作为正式注册结论。
- 传播语：**把波动，变成可检验的节奏。** 强调观察、策略与复盘，不作收益承诺。
- 视觉系统：近黑海军蓝为底、单一青柠色作为主操作强调色，水青色作次级信号；圆角克制、细边框与清晰留白形成高密度但安静的交易工作台。
- 标记：双层潮线与一个信号节点的简化 SVG；不借用交易所或现有品牌标识。

## 参考与取舍

- Awwwards 检索未发现可直接参考的交易工作台案例，因此按项目规则回退到设计案例来源。
- [Finaura fintech dashboard case study](https://arturmineev.com/projects/finaura/)：借鉴“暗色底 + 单一明亮强调色”、减少同时展示的装饰项、以轻柔动效表达界面状态；本项目将其改成更适合长时间盯盘的紧凑模块、明确的风险状态、固定侧栏和纸面模拟标签，没有复刻其屏幕布局或资产。
- [Refero](https://refero.design/)：用作筛选真实产品模式的替代入口，重点采纳图表摘要、筛选粒度、活动/通知占位与可扫描的表格信息层级；目前只有来源目录级检索，尚未获取具体产品截图，因此这些属于通用模式参考。
- 开源核对：[strata-pro-crypto-ui](https://github.com/bymilon/strata-pro-crypto-ui) 与 [frontend-trading-dashboard](https://github.com/maddoxk/frontend-trading-dashboard) 均为 MIT，但检查时都只有一个提交、零 Star，维护成熟度不足；它们依赖 React/Vite 等，而原项目没有前端运行时。因此不复制代码、不增加依赖，采用原生 HTML/CSS/JS 独立呈现本地原型。成熟交易系统的策略/数据分层仍以项目根 `README.md` 已有记录为参考。

## 状态与边界

- 登录页为真实的本机邀请码入口，没有公开注册/演示绕过按钮；服务端未认证时仅提供登录页与必要资源，工作台 HTML、脚本和回测模块需要有效服务端会话。邀请码通过环境变量注入、只驻留进程内；会话为内存映射的随机 token，12 小时有效、服务重启即失效，失败尝试有限流。
- 认证边界严格限于本机预览：服务绑定 `127.0.0.1`，邀请码是共享访问码而非个人账户，不能远程撤销单个用户，也不能防止本机管理员绕过。正式销售版本需另建 HTTPS 中央身份服务、用户级邀请与撤销流程。
- 行情面板由 `workbench/simulator.js` 的确定性合成价格序列驱动；绩效卡片、权益曲线和交易表由本地模拟平仓记录计算。工作台从当前浏览器本机存储恢复账本与参数，刷新后仍保留。
- “启动纸面模拟”执行离线样本生成 → 策略判断 → 本地风控参数评估 → 纸面记账，不连接 CLI、网络、账户或交易所。
- 纸面账本、累计指标、风险偏好与策略参数保存在当前浏览器本地存储，刷新后恢复；交易日志提供清空本地记录入口。该存储仅服务于单机演示，不是账号级/跨设备同步。
- 脉冲动量、区间突破、均值回归均已进入本地合成样本回放。资产、1秒/5秒/15秒/1分钟频率与风险滑杆会改变样本、信号门槛、名义上限、停止线及结果；费用和滑点为测试假设。不能把这些样本结果当作策略有效性或实盘高频能力证据。
- 新增“本地历史回测”：浏览器通过本地文件选择读取 OHLCV CSV，并调用构建后的回测模块；文件由浏览器读取，不经服务器处理。服务器仅提供登录验证和静态工作台资源，没有行情/账户/交易所 API；CSP 只允许同源请求。仅支持严格的 `timestamp,open,high,low,close,volume` 表头、升序且等间隔的 K 线；按选择的策略、标的标签、周期与风险分数运行样本内回测，标签由用户自行确认。最大文件 20 MB / 250,000 根；未提供数据缺口修复、币种自动识别、样本外验证或外部行情抓取。
- 官方公告窗口预留给后续具备管理授权和审计的服务；当前为空，不伪造官方推送。

## 邀请访问方案核对

- 已核对 [Better Auth 禁用注册选项](https://better-auth.com/docs/reference/options) 与 [Fastify Secure Session](https://github.com/fastify/fastify-secure-session)。两者适合进一步建设有用户/数据库或 Fastify 服务的身份系统；本地预览保留原生 Node 静态服务，不引入这些运行依赖。
- 当前仅实现本机体验门：高熵邀请码摘要、恒定时间摘要比较、HttpOnly/SameSite 会话 Cookie、会话 TTL 和尝试限流；这组自定义代码不作为远程/商业认证安全背书。
